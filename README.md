# DOF Crop Nutrition Guide — 고객용 웹페이지

도프(DOF LTD.) 제품의 작물별 사용 시기·사용량 안내 페이지입니다. **가격 정보는 들어 있지 않습니다.**
고객이 면적을 넣으면 필요 수량이, 현지 가격을 넣으면 비용이 자동으로 계산됩니다.

- 영문 전용(해외 고객용). 한국어 메뉴와 국내 화면은 넣지 않았습니다.
- 파일은 `index.html` 하나입니다.

- 11개 작물: 고추(노지·시설), 사과, 포도, 토마토, 오이, 양파, 마늘, 복숭아, 배, 감귤
- 제품 사진·카탈로그(45쪽)가 파일 안에 들어 있어 외부 서버나 인터넷 연결 없이도 동작합니다.
- 고객이 입력한 가격·면적은 그 고객의 브라우저에만 저장되며, 이 저장소나 회사로 전송되지 않습니다.
- 문의 양식은 메일 작성 창(dofltd.intl@gmail.com)으로 연결됩니다.
